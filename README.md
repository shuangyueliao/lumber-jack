# Lumber Jack · Chop the Tree

Free single-file HTML5 arcade timing game. Stand beside the giant tree, chop
left or right, and never let a falling branch catch you — fast chops build a
x2 combo, rare gold branches pay +5, and the timer bar shrinks as you score.
One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/lumber-jack/

- Left / right half-screen touch + ←/→ or A/D keys + mouse click on either side
- Refilling timer bar (starts at 2.5 s per bar, tightens down to 0.9 s)
- Branch generation always leaves one safe side — no dead-end positions
- Procedural tree with bark texture & growth-ring cross-sections, 3-frame axe
  swing, wood-chip particles, flying chopped segments, parallax forest
  silhouettes, day/night cycle every 50 points
- Best score saved locally (try/catch safe), mute toggle
- Procedural WebAudio sounds (chop, gold chime, death, phase change)
